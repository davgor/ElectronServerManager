# 042.7 — Enshrouded 1.0 launch-day verification

Follow-up from epic **042** (Enshrouded Palworld-parity ops). Everything in 042.1–042.6 is unit-tested with fake UDP transports and a loopback socket, but no real Enshrouded server was available: the 1.0 dedicated-server build ships on 2026-10-15 and Steam had only the 2026-05-12 `public` build (23178631) before launch. This ticket is the live check against the real 1.0 server, done with a **clean 1.0 world**, plus anything the check turns up.

Research context lives in the epic's "1.0 release check" notes.

## Acceptance criteria

- [x] Update the server to the 1.0 build (SteamCMD app `2278520`); first boot vanilla with a fresh world; record the new buildid here — buildid **25936466** (installed 2026-10-15 15:18 UTC, readme "Version: 1.0.0.0"); fresh world loads to `Run` ~11 s after start, while `[Session] 'HostOnline' (up)!` already logs at ~1.5 s, so HostOnline is not a "fully started" signal on 1.0
- [x] With the server running, the Enshrouded card's **Live ops** panel shows server name, version and `0/N` players; the version string matches 1.0 — server name and `0/16` confirmed in the app (2026-10-15).
